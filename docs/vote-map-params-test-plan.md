# `/vote map` 双大括号参数实机测试计划

## 1. 测试目标

验证 `voteMap.kts` 与 `unlimited.kts` 两个插件在真实客户端、真实投票和真实换图流程中是否正常，重点覆盖普通玩家最容易触发、且自动测试覆盖不到的部分。

测试前确认：

- 使用临时测试服，不直接在生产服测试。
- 备份 `config/scripts/external-cp/` 与测试用地图。
- 至少准备 2 个客户端账号：一个普通玩家、一个管理员。
- 准备一个带空格文件名的 CP，例如 `亚龙组合包 (1).zip`。
- 准备一个不存在的 CP 名称，用于失败路径。
- 记录当前地图 ID、下一张地图 ID，以及当前 `Vars.state.rules.infiniteResources` 状态。

## 2. 未验证风险（当前版本）

以下项目尚未完成实机验证，应作为本轮重点：

1. **真实客户端命令链路**
   - 客户端输入、引号、空格经过命令分词后是否仍按预期解析。
   - 服务端 `arg.drop(1).joinToString(" ")` 是否会压缩连续空格。

2. **投票通过后的 DP 实际加载**
   - 投票只验证了“参数写入 rules.tags”。
   - 尚未证明 `mapDpTags` 在真实 `MapLoadFinishedEvent` 中一定读取到 `@dp` 并成功加载。
   - 需要验证 CP 文件名大小写、扩展名、带空格名称。

3. **DP 失败路径**
   - 投票通过后文件被删除/损坏时，地图是否仍会换图。
   - DP 加载失败是否会留下半加载状态。
   - 本功能不会回滚换图。

4. **`@pure=false` 的时序**
   - `@pure` 标签脚本在换图时按什么顺序卸载。
   - 关闭纯净模式后，旧地图的 pure 状态是否残留。

5. **`@Unlimited` 的生效与恢复**
   - 已用临时换图验证：带 `@Unlimited=true` 换入后 `infiniteResources=true`；换回无标签地图后恢复 `false`。
   - 仍需在**真实 `/vote map` 投票链路**中复验，并确认其它脚本局中修改该字段时的恢复行为。

6. **51% 投票门槛的治理风险**
   - 带 DP 的地图投票仍是 51%，低于 `/vote cp` 的 70%。
   - 普通玩家可通过地图投票附带 DP，存在绕过严格 CP 投票的风险。
   - 本轮不调整门槛，只验证行为。

7. **`@Unlimited` 冷启动加载链路**
   - 命令校验只检查脚本是否存在于 `ScriptRegistry`，**不检查是否已启用**；脚本存在但未启用时仍会通过校验。
   - 冷启动第一张带 `@Unlimited` 的图，必须依赖 `TagSupport.fallbackTags` 的 `@Unlimited -> mapScript/tags/unlimited` 映射；否则会拼成 `mapScript/tags/Unlimited` 而静默失败。
   - 复现步骤：冷启动 → `scriptdiag state mapScript/tags/unlimited`（应显示未启用）→ 走一次 `{}{[@Unlimited=true]}` 换图 → 检查是否出现 `[Load] mapScript/tags/unlimited` 且 `infiniteResources=true`。

8. **CP 目录配置**
   - 当前校验写死默认目录 `config/scripts/external-cp`。
   - 如果服务器修改了 `externalCpHotReload` 的目录配置，校验会失效。

9. **多空格文件名**
   - 命令入口按空格分词后拼接，连续多个空格会被压缩。
   - 含连续空格的 CP 文件名可能无法通过。

## 3. 必测用例

### A. 旧行为回归

| 用例 | 输入 | 预期 |
|---|---|---|
| 旧命令 | `/vote map 114514` | 与旧版完全一致，无 DP/标签变更 |
| 旧命令 + 空块 | `/vote map 114514 {}` | 只换图，忽略空块 |
| 双空块 | `/vote map 114514 {}{}` | 只换图 |
| 地图筛选拦截 | 被 mapFilter 阻止的地图 | 不创建投票，提示原因 |

### B. 解析与拒绝

| 用例 | 输入 | 预期 |
|---|---|---|
| 三个块 | `...{} {} {}` | “最多只能提供两个大括号参数”，不发起投票 |
| 块外字符 | `...{} x` | 格式错误，不发起投票 |
| 第二块 CP | `...{}{[@dp=true]}` | “第二块不能设置 CP 标签” |
| 未知标签 | `...{}{[@NotARealTag=true]}` | 未知标签拒绝 |
| 重复标签 | `...{}{[@pure=true][@pure=false]}` | 重复标签拒绝 |
| 不存在的 CP | `...{[@dp=不存在.zip]}{}` | “服务器 CP 不存在” |
| 非法文件名 | 含 `,`、`;`、`[`、`]`、`=`、`|` | 拒绝 |
| 引号不匹配 | `...{[@dp="abc.zip]}{}` | 大括号/引号未闭合错误 |

### C. DP 参数

| 用例 | 输入 | 预期 |
|---|---|---|
| 单个 DP | `{[@dp=赛克兰特高阶科技.zip]}` | 投票描述含 DP；通过后加载 |
| 多个 DP | `{[@dp=包A.zip,包B.zip]}` | 两个都加载 |
| 带空格文件名 | `{[@dp="亚龙组合包 (1).zip"]}` | 正常识别并加载 |
| 无扩展名 | `{[@dp=赛克兰特高阶科技]}` | 自动补 `.zip` 后找到 |
| 大小写 | `{[@dp=SAKELANTE.ZIP]}`（实际小写文件） | 大小写不敏感匹配 |
| DP 文件删除后再投票通过 | 先通过投票，换图前删除文件 | 地图可能仍切换，DP 加载失败；记录日志 |
| 地图自带 `@nodp` | `{[@dp=包A.zip]}{}` | 命令阶段拒绝：“该地图自带 @nodp，不能通过投票附加 DP” |
| 第二块混合 | `{}{[@pure=true][@Unlimited=true]}` | 只应用标签，不加载 DP |

### D. 标签参数

| 用例 | 输入 | 预期 |
|---|---|---|
| 开启 pure | `{}{[@pure=true]}` | 本局 pure 生效 |
| 关闭 pure | 地图已带 pure，再 `{}{[@pure=false]}` | 本局 pure 移除，旧状态不残留 |
| 开启 Unlimited | `{}{[@Unlimited=true]}` | 本局 `infiniteResources=true` |
| 关闭 Unlimited | 地图已带 Unlimited，再 `{}{[@Unlimited=false]}` | 不开启无限资源 |
| 同标签 true+false | `{}{[@pure=true][@pure=false]}` | 拒绝 |
| 标签大小写 | `{}{[@unlimited=true]}` | 接受；与 `@Unlimited` 等价，均映射到 `mapScript/tags/unlimited` |
| 标签 + DP | 两个块同时存在 | 两者都应用，顺序为 DP 后标签 |

### E. 投票与换图

| 用例 | 操作 | 预期 |
|---|---|---|
| 51% 通过 | 2 人赞成 / 1 人反对 | 通过并换图 |
| 未达 51% | 1 人赞成 / 1 人反对 | 不通过，参数不生效 |
| 取消投票 | 发起后取消 | 不换图，pending 清理 |
| 管理员换图 | 投票期间管理员换到其它地图 | 目标不匹配，不误应用参数 |
| 地图加载失败 | 投票通过但地图损坏 | 不应用/清理 pending，记录错误 |
| 连续两次投票 | 第一次未完成再发起 | 仍只允许一个全局投票，行为与旧版一致 |

### F. 状态清理

| 用例 | 操作 | 预期 |
|---|---|---|
| 下一张地图不带参数 | 正常换图 | 上一局 `@dp`/标签不残留 |
| 投票失败 | 否决/取消 | pending 为空，不污染下一次 |
| 换图异常 | 强制取消 MapChangeEvent | pending 清理 |
| `@Unlimited` 换图 | 带标签换入，再换出 | 恢复进入前状态，下一局不误开 |
