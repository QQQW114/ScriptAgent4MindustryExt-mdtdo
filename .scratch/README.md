# 本地临时草稿箱（不入库）

本目录除本说明文件外，其余所有文件均被 `.gitignore` 忽略，**永远不会被提交到 Git 仓库**。

## 什么内容放这里

- 开发过程中的临时排查笔记、草稿、方案推演；
- 单次改动的测试计划、实机测试勾选清单、临时日志摘录；
- 中间数据或一次性验证输出。

## 什么内容不能放 `docs/`

测试计划（`*-test-plan.md`）、单次审计报告（`*-audit.md` / `*-report.md`）、临时任务列表（`temp-*.md`）、会话总结等过程产物，请放在本目录，**不要提交进 `docs/`**。需要留档的进度与验证证据请写在对应 **GitHub Issue / PR 描述**中。
